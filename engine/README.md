# Vendored Kimi Code engine

This directory contains the MIT-licensed [Kimi Code](https://github.com/MoonshotAI/kimi-code)
engine used by OpenAqua Harness for sessions, model providers, tools, terminal UI,
and local Web serving.

Install and run the product from the repository root using the
[OpenAqua Harness README](../README.md). Product configuration, desktop builds,
and GitHub releases are managed there.

For engine changes, follow [AGENTS.md](./AGENTS.md) and retain the upstream
[LICENSE](./LICENSE). Keep product-specific behavior under
[`apps/openaqua-harness`](./apps/openaqua-harness) where possible.
