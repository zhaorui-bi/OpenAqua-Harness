# 内嵌的 Kimi Code 引擎

本目录保留 MIT 许可的 [Kimi Code](https://github.com/MoonshotAI/kimi-code)
引擎，为 OpenAqua Harness 提供会话、模型接入、工具、终端界面与本地 Web 服务。

请从仓库根目录按 [OpenAqua Harness README](../README.zh-CN.md) 安装和运行。
产品配置、桌面构建和 GitHub 版本发布统一在根目录管理。

修改引擎前请遵循 [AGENTS.md](./AGENTS.md)，并保留上游
[LICENSE](./LICENSE)。产品专属行为优先放在
[`apps/openaqua-harness`](./apps/openaqua-harness) 中。
